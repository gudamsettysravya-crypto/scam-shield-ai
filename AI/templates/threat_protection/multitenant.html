Strict Row-Level Data Isolation

Every analysis, uploaded screenshot, and generated PDF report is tagged with the tenant's cryptographic user ID.

  • Query-level filtering: All database queries enforce strict WHERE user_id = ? clauses at the database driver layer.
  • Zero Cross-Tenant Leakage: User A can never query, read, edit, or download User B's incident reports, even if manipulating URL parameters.
  • Cascading Data Erasure: When a user removes a report or closes an account, their records are purged cleanly without remnants.
Cryptographic Authentication & Secrets

Industry-standard cryptographic primitives secure each tenant's credentials and session tokens.

  • Salted Password Hashes: User credentials are protected using Werkzeug scrypt/PBKDF2 hashing algorithms with high work factors.
  • Secure Session Tokens: HTTPOnly, SameSite cookie policies prevent cross-site request forgery and cookie theft.
  • Privilege Separation: Tenant session state is kept separate from backend AI model execution buffers.
Anonymized Threat Intelligence Sharing

Scam patterns are aggregated across tenants for community defense without exposing personal identity or raw message contents.

  • Differential Privacy: Only high-level category counts (e.g. "UPI scams up 14%") feed into the community trends dashboard.
  • PII Stripping: Phone numbers, names, and personal identifiers are never included in aggregated metrics.
  • Collective Immunity: Emerging scam variants detected in one tenant improve detection heuristics across the entire platform.
Enterprise & Organization Ready

Designed for corporate cybersecurity teams, universities, and banking customer support operations.

  • Departmental Sandboxing: Support for organizational teams to manage fraud tickets collaboratively.
  • Forensic Audit Trails: Timestamped PDF reports ready for submission to law enforcement or legal teams.
  • Regulatory Alignment: Compliant with Digital Personal Data Protection (DPDP) principles.
